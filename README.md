# College Attendance & Bunk Tracker

A simple Python CLI tool I made to track my college attendance and calculate how many classes I can safely bunk to maintain the 75% criteria.

### Features
- Saves subject-wise attendance locally using a JSON file (my_attendance.json)
- Calculates exact number of classes to attend in a row if below 75%
- Shows how many classes can be safely skipped if above 75%
- Simple terminal progress bar for each subject
